РЕТУШЬ — КАК ПРЕВРАТИТЬ В ПРИЛОЖЕНИЕ
=====================================

Что нужно: бесплатный аккаунт на GitHub (github.com). Платить ничего не надо.
Сайт нужен один раз — потом приложение работает и без интернета.

1. ВЫЛОЖИТЬ ФАЙЛЫ (5 минут, один раз)
   1) Зарегистрируйтесь на github.com.
   2) Справа вверху «+» → New repository.
      Имя: retush. Отметьте Public. Нажмите Create repository.
   3) На странице репозитория нажмите ссылку «uploading an existing file».
   4) Перетащите ВСЕ файлы из этой папки (не саму папку, а то, что внутри).
      Нажмите зелёную кнопку Commit changes.
   5) Settings → Pages (слева). В «Branch» выберите main и / (root) → Save.
   6) Подождите 1–2 минуты. Адрес приложения:
         https://ВАШ-НИК.github.io/retush/

2. УСТАНОВИТЬ
   Android (Chrome):  открыть адрес → ⋮ → «Установить приложение»
                      (или «Добавить на главный экран»).
   iPhone (Safari):   открыть адрес → кнопка «Поделиться» → «На экран Домой».
   Windows / Mac (Chrome или Edge): открыть адрес → значок установки
                      в адресной строке или кнопка «Установить» в самом редакторе.

   После этого у Ретуши своя иконка, своё окно без браузера,
   и она работает без интернета.

3. ПОЛЕЗНО ЗНАТЬ
   - На компьютере после установки картинки можно открывать через
     правый клик → «Открыть с помощью» → Ретушь.
   - На телефоне: двумя пальцами — масштаб и сдвиг холста.
   - Фото никуда не загружаются: всё обрабатывается на вашем устройстве.
   - Обновить приложение: замените index.html на GitHub новым
     и в файле sw.js поменяйте retush-v1 на retush-v2.
